How to install on Android

  1. Tap Download for Android. If Chrome warns that the file may be harmful, tap Download anyway. This warning shows for every app from outside the Play Store.
  2. Open the downloaded file (from the notification or Files → Downloads).
  3. If asked, allow Install unknown apps for Chrome, then go back and tap Install.
  4. If Google Play Protect asks, tap More details → Install anyway.
  5. Open Vastu Prop, allow motion and location when asked, and run your first check.
